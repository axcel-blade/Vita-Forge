# Support

## How to Get Help

### Bug reports and feature requests

Use the GitHub issue tracker:

- [Report a bug](.github/ISSUE_TEMPLATE/bug_report.md)
- [Request a feature](.github/ISSUE_TEMPLATE/feature_request.md)

Search existing issues before opening a new one — your question may already be answered.

### General questions

Open a [GitHub Discussion](https://github.com/axcel-blade/vita-forge/discussions) for questions that are not bugs or feature requests.

### Direct contact

For security vulnerabilities, see [SECURITY.md](SECURITY.md).

For other private matters, contact the maintainer at **srikanthfernando3@gmail.com**.

---

## Before Asking for Help

Please check:

1. The [README.md](README.md) for setup and usage instructions.
2. The [backend/CHANGELOG.md](backend/CHANGELOG.md) or [frontend/CHANGELOG.md](frontend/CHANGELOG.md) to see if your issue was already fixed in a newer version.
3. The browser console for error messages (F12 → Console tab).

---

## Out of Scope

This project does not provide support for:

- Customising the resume templates beyond the built-in editor options
- Integrating with third-party services
- Running the project in unsupported environments (Node.js < 20, npm < 10)
